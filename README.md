# x'save

一款用于下载 X / Twitter 图片与视频的**油猴脚本**，通过 Tampermonkey 运行。安装后，网页中的图片和视频旁会出现下载按钮，点击即可保存媒体，也可以单独复制视频地址。

## 功能

- **图片下载**：优先请求原图，失败时尝试其他尺寸；支持个人资料背景图。
- **视频下载**：按码率从高到低尝试 MP4 地址，失败后尝试 HLS 分片下载与合并。
- **HLS 合并**：自动下载视频分片，将兼容的音视频轨道合并为 MP4。
- **视频地址复制**：列出可用的 MP4 码率版本与 HLS 播放列表，点击即可复制完整地址。
- **多媒体下载**：通过媒体集合上的下载按钮，依次保存同一推文中的图片与视频；平台上的 GIF 动图按视频处理。
- **下载历史**：标记已下载媒体，支持导出、导入和合并记录。
- **页面增强**：提供隐藏趋势、已访问链接高亮、直达链接、页面标题优化等可选设置。
- **下载进度**：在下载按钮上查看进度和当前状态。


## 使用

### 下载图片与视频

打开包含媒体的时间线、推文详情或媒体页面，点击媒体上的下载按钮。视频会优先尝试最高码率的 MP4；没有可用 MP4 时，会尝试获取 HLS 分片并合并保存。

文件名会尽量包含作者、日期、推文 ID 和媒体名称，便于整理。下载完成后，请到浏览器下载列表确认文件是否已保存。

### 复制视频地址

- 点击视频下载按钮旁的地址列表开关，查看可用的 MP4 与 HLS 地址。
- 点击列表中的一项复制完整地址；自动复制失败时，可使用面板中的输入框手动复制。
- HLS 的 `.m3u8` 地址是播放列表，需要下载分片并合并，不能直接改扩展名当作 MP4 使用。


## 常见问题

### 页面没有下载按钮

确认油猴扩展和 **x'save** 脚本均已启用，允许油猴在当前网站运行，并在安装后刷新页面。也可在脚本设置中检查 **Image Download Button** 和 **Video Download Button** 是否开启。

### 视频信息获取失败或无法匹配视频

先确认当前账号可以正常查看该推文，再打开推文详情页重试。脚本依赖平台的页面结构和接口；平台改版可能导致功能失效。

Firefox 用户可在脚本设置中检查 **Strict Tracking Protection Fix** 选项。

### HLS 下载或合并失败

先检查网络，再尝试在油猴中重新保存或安装脚本，确保视频合并依赖已加载。部分视频编码不支持直接合并为 MP4，分片请求失败也可能中断下载。

### 按钮显示完成，但找不到文件

脚本只能确认已触发浏览器保存，无法确认文件最终写入磁盘。请检查浏览器下载列表、保存目录及多文件下载权限。媒体数据会暂存在内存中，大视频下载与合并可能占用较多内存。
